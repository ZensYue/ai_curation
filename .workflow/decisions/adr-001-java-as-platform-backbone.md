# ADR-001：平台主干采用 Java + Spring Boot

## 结论

`ai_curation` 的平台主干长期采用 `Java + Spring Boot` 建设。

## Why

项目定位已经明确为平台化产品，而不是单一自动化工具。平台主系统需要长期承载：

- 账号体系
- 权限控制
- 客户与业务管理
- 任务流转
- 审计与日志
- 后续营销与运营能力

这类能力更适合用 Java 作为长期平台主干，便于多人协作、长期维护、模块扩展与服务治理。

## 当前适用边界

本结论适用于：

- 主平台后端
- 平台级业务模块
- 账号、权限、任务、通知等长期能力建设

不适用于爬虫能力域本身。

## 何时重审

如果未来项目范围显著收缩，不再建设平台主系统，而只保留轻量工具形态，可重新评估。当前阶段不重审。
