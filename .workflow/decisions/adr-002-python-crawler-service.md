# ADR-002：爬虫能力域独立采用 Python 服务承载

## 结论

爬虫能力域采用 `Python` 独立服务建设，而不是直接并入平台主后端。

## Why

虽然主平台采用 Java，但爬虫能力域更适合 Python，原因包括：

- 多站点适配开发效率更高
- 浏览器自动化生态更成熟
- HTML 解析、数据清洗、文本处理更顺手
- 更适合快速应对页面结构变化和反爬变化
- 后续接 AI 做标题清洗、型号标准化、语义处理更自然

这不是重复建设，而是按职责做合理分工。

## 当前适用边界

本结论适用于：

- `crawler/` 子项目
- 平台适配器、抓取执行、解析、落盘、回调相关能力

当前阶段先做一个独立 Python 服务，不按平台拆成多个独立部署服务，但代码内部应保持 adapter 化边界。

## 何时重审

如果未来某个平台复杂度显著升高，达到独立部署收益明显高于成本时，可以重审“单服务内部 adapter 化”这一层，而不是重审 Python 作为爬虫能力域语言的结论。
