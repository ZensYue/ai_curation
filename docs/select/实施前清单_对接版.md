### 2. 商品标准化与映射

- 型号标准化是靠规则表、AI，还是两者结合？
当前反馈：尽量依靠 AI 进行判断和筛选统一标准，因为后续产品会越来越多。

- “品牌一致 + 型号一致” 是否足够作为去重规则？
当前反馈：这是最基本规则，如需更细可增加颜色等属性。

- 颜色、容量、套餐是否算同款？
当前反馈：颜色不算同款；容量和套餐通常已包含在型号中，例如手机 `16GB+256GB` 即可视为型号的一部分。如对标准理解有偏差，可再讨论细化。

- 如果平台标题混乱，是否允许人工维护映射表？
当前反馈：需结合实际工作量再判断。

### 3. 业务规则与判定标准

- 浏览量、收藏数、近 `7` 天新增评价是否都能拿到？
- 拿不到时是否允许用替代指标？
- “蓝海产品”中的 “KP 供应稀缺 / 热度不高” 如何定义？
- 最低利润额和利润率门槛是多少？
- 哪些商品类型需要直接剔除？

当前反馈：大部分问题在前文已有回答；拿不到时可以再讨论是否有其他合适指标替代。利润率不是硬性要求，也可以先把价格和利润核算出来，由业务侧自行判断，后续再持续优化。

### 4. 成本、汇率与本地比价

- 国内采购成本按标价、到手价还是最低采购价？
当前反馈：拼多多、京东和淘宝几个平台优先使用调研到的标价，且优先选最低价。

- `ePonuda` 搜不到商品时是否继续利润核算？
当前反馈：`ePonuda` 搜不到商品不影响利润核算，只是最低价字段为空；最低价是参考信息，不是利润核算的核心输入。

- 尾程费用是否按国家拆分？
当前反馈：不用，直接按已提供信息筛选匹配即可。

## 三、建议结论整理

基于当前对接信息，可先形成以下初步实施共识：

- 首期重点平台为 `KP`、`Alza`、`MediaMarkt`，国内侧重点为淘宝、京东、拼多多。
- 类目重点集中在手机、相机、运动相机、电脑设备、配件、充电宝等电子产品。
- `Vika` 前期先做分表验证数据质量，再决定是否建设主看板汇总表。
- 更新策略以覆盖更新为主，更新频率暂定 `1-2 天`。
- 利润率门槛可先按 `50%` 作为参考值，但不作为绝对硬约束。
- 物流参数中空运单价按 `100 元/kg` 覆盖默认值，其他参数继续沿用文档默认值，后续支持动态修改。
- 新品监控建议优先落地 RSS 聚合方案，再逐步补品牌官网和科技媒体数据源。

## 四、建议实施顺序

1. 先确认平台与账号资料
2. 先定 `Vika` 表结构
3. 再定商品标准化与去重规则
4. 再定潜力筛选阈值
5. 再定利润核算参数
6. 最后开始拆 `n8n` 流程并实施
