# AI 选品 (AI Curation)

这是一个多服务架构的 AI 选品项目。目前处于早期验证阶段。

## 目录结构
- `scripts/`: 用于存放验证性的 Python 脚本
- `notebooks/`: 用于存放 Jupyter Notebook 实验和数据分析
- `src/`: 未来多服务架构的代码存放地（待技术选型后细化）
- `docs/`: 项目文档

## 开发计划
1. **初期验证**: 使用 Python 快速进行业务逻辑和 AI 模型的能力验证。
2. **技术选型**: 根据验证结果和团队规划，确定最终的前后端技术栈（例如 Go、Java、Node.js、React 等）。
3. **服务化**: 将验证过的逻辑拆分为多服务架构进行落地。
